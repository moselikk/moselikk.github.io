[PulseBar](https://github.com/moselikk/pulsebar) 是一个专为 macOS 设计的轻量级状态栏硬件与系统监控小工具。使用 Rust 与 macOS 原生 AppKit 开发，不依赖 WebKit / Webview，注重低资源占用与系统原生质感。

---

## 为什么写这个工具

在日常使用 Mac 时，经常需要关注 CPU 负载、内存用量或网络实时速率。市面上的监控软件大多存在以下问题：
- 基于 Electron 或 Webview 构建，常驻内存与电量开销偏大；
- 状态栏显示过宽，占用过多刘海屏两旁的宝贵空间；
- 功能繁重冗余，缺乏轻巧克制的交互体验。

PulseBar 的目标是做一款极简、纯粹、低开销的菜单栏小工具，平时安静常驻，需要时一键查看关键硬件指标。

---

## 核心特性

- **原生与极低占用**：基于 Rust 与 AppKit，无前端引擎开销，常驻内存仅数兆。
- **按需智能采样**：状态栏常驻仅通过 macOS Mach 内核低频采集必要数据；点击展开面板时才启动波形与细粒度采样，不额外消耗性能与电池。
- **紧凑布局与原生质感**：双行紧凑对齐，极小化占用状态栏宽度；原生毛玻璃背景，自适应 macOS 深浅色模式。
- **全面的硬件指标**：
  - **CPU**：总利用率、历史波形图、多核核心分布与系统负载。
  - **内存**：已用 / 总量，细分活跃、联动、压缩与可用内存。
  - **I/O 速率**：实时网络上传 / 下载速率与磁盘读写速率。
  - **SMC 传感器**：CPU 温度与风扇转速。
  - **Top 进程**：动态追踪高资源占用的进程与 PID。
- **细节配置**：支持开机自启、多种字体风格切换（medium / regular / semibold / mono 等）、多语言自适应（简中 / 繁中 / English）。

## 下载与使用

- [PulseBar Releases](https://github.com/moselikk/pulsebar/releases)

下载 `PulseBar.dmg` 后拖入 `Applications` 文件夹即可使用。也可以根据需要在 `~/.config/pulsebar/config.toml` 中进行个性化配置。
