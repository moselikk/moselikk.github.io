# Moselikk's Personal Blog (Modern Vanilla SSG Edition)

这是使用现代前端工具链重构的个人主页工程（https://www.moselikk.com/）。

## 特性

- 🚀 **纯粹零框架运行时**：基于 Node.js + TypeScript + Unified + Shiki + SCSS 自研的极速 SSG 静态站点生成体系。
- 🎨 **1:1 还原经典设计**：保留衬线宋体排版、响应式表格适配、暗黑模式自适应。
- 💡 **现代语法高亮**：采用 Shiki 的 GitHub Light / GitHub Dark 双主题代码高亮。
- 🏮 **原汁原味彩蛋**：一言（Hitokoto + 60s 缓存）、农历春节初一至初八灯笼动画。
- 💬 **评论支持**：原生保留 Gitalk 评论容器。
- 📡 **完整 SEO 与订阅**：自动生成 `feed.xml`、`sitemap.xml`，保留 GTM 容器追踪。
- 🔄 **自动部署**：配置 GitHub Actions 工作流，一键部署到 GitHub Pages。

## 常用命令

```bash
# 安装依赖
npm install

# 本地静态构建
npm run build

# 本地实时开发预览
npm run dev

# 产物预览
npm run preview
```
